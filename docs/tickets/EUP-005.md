# EUP-005 — Optional account auth

| Field | Value |
|-------|-------|
| **Status** | Backlog |
| **Phase** | Phase 2 |
| **Labels** | `phase-2`, `feature` |

## Summary

Add Auth.js (NextAuth v5) with **open registration**. Logged-in users reuse a display name across parties; guests can still join with nickname only. **Only the site admin may create parties** — see [EUP-029](EUP-029.md). Absorbs [EUP-027](EUP-027.md) (participant account linking).

## Acceptance criteria

- [ ] Register and login flows
- [ ] Login providers: **email + password**, **magic link**, **Google OAuth**
- [ ] Open registration — anyone can sign up; non-admins are join-only
- [ ] Logged-in users join with their linked display name (no separate nickname pick each time)
- [ ] Guests can still join with party code + nickname only
- [ ] Users table and migration from MVP schema documented
- [ ] Non-admin users cannot create parties (implemented with EUP-029)

## Dependencies

- MVP complete (EUP-017)
- Ship together with [EUP-029](EUP-029.md)

## Key decisions (locked)

- **Registration:** open (not invite-only)
- **Guest join:** nickname-only remains available
- **EUP-027:** merged here — no separate ticket
- **Build order:** first Phase 2 item (with EUP-029)
