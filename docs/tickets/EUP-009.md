# EUP-009 — Real-time voting status

| Field | Value |
|-------|-------|
| **Status** | Backlog |
| **Phase** | MVP (Phase 1) |
| **Labels** | `mvp`, `feature` |

## Summary

Socket.io party rooms broadcast **who has voted** to all clients. Reconnect resync. Never broadcast point allocations during voting.

## Acceptance criteria

- [ ] Join party room on connect with party id
- [ ] `vote_submitted` / `voting_status` events update all clients
- [ ] Reconnect restores participant vote status without leaking scores
- [ ] Supports **8–10 simultaneous** connections in one party (smoke target)
