# EUP-003 — Country entry picker (custom)

| Field | Value |
|-------|-------|
| **Status** | Backlog |
| **Phase** | MVP (Phase 1) |
| **Labels** | `mvp`, `feature` |

## Summary

Host adds and removes countries for a party manually (name + flag emoji or image). Require at least **5 entries** before voting can start.

## Acceptance criteria

- [ ] Host can add, edit, and remove entries while party is in draft/lobby
- [ ] Each entry has display name and flag representation
- [ ] Validation blocks starting voting with fewer than 5 entries
- [ ] Entries persist per party in `party_entries`

## Dependencies

- EUP-002

## Key decisions

- No Eurovision year import in MVP (Phase 2: EUP-020/EUP-021).
