# EUP-044 — Searchable country combobox in ballot

| Field | Value |
|-------|-------|
| **Status** | Done |
| **Phase** | Phase 3 |
| **Labels** | `phase-3`, `feature` |

## Summary

Replace the vote ballot country dropdown with a **type-to-filter combobox** so jurors can quickly pick countries when assigning 1–12 points.

## Acceptance criteria

- [x] User can type partial country name and select from filtered party entries
- [x] Works on mobile (virtual keyboard does not break layout)
- [x] Already-picked countries are disabled / not selectable in other slots
- [x] No regression to 12-point allocation flow or submit validation

## Dependencies

- [EUP-007](EUP-007.md) — classic ballot

## Key decisions (locked)

- Combobox pattern with keyboard nav (arrows, Enter, Escape)
- Reuse `.country-select` styling from lobby autocomplete
