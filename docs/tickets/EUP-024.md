# EUP-024 — Party history list

| Field | Value |
|-------|-------|
| **Status** | Backlog |
| **Phase** | Phase 2 |
| **Labels** | `phase-2`, `feature` |

## Summary

List past parties. **Admin** sees all parties on the server. **Logged-in guests** see parties they participated in.

## Acceptance criteria

- [ ] Admin history page: date, party code, winner, participant count
- [ ] Guest history (logged-in): parties they joined as a participant
- [ ] Nickname-only guests: no persistent history list (or prompt to create account)
- [ ] Links to party detail / replay (EUP-025)

## Dependencies

- EUP-005 (accounts for guest-scoped history)
- EUP-011 results snapshot (finished parties)

## Key decisions (locked)

- **Visibility:** admin = all; guests = participated only
- **Build order:** third Phase 2 wave (with EUP-025, EUP-026)
