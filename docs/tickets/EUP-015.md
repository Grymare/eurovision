# EUP-015 — Real-time presentation sync

| Field | Value |
|-------|-------|
| **Status** | Backlog |
| **Phase** | MVP (Phase 1) |
| **Labels** | `mvp`, `feature` |

## Summary

All connected clients (host, guests, presentation screen) stay in sync during reveal via Socket.io `presentation_reveal` and scoreboard events.

## Acceptance criteria

- [ ] Host actions broadcast to entire party room
- [ ] Late reconnect during presentation resyncs current step
- [ ] No vote data leaked in events beyond current reveal step
- [ ] Works with multiple simultaneous viewers (TV + phones)

## Dependencies

- EUP-014

## Key decisions

- Same room model as EUP-009; scale target **5–15 guests**.
