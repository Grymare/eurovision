## Summary

Bootstrap Next.js (App Router), TypeScript, Tailwind, Drizzle, SQLite (WAL), Socket.io on a custom Node server, and Docker Compose for LAN dev on Windows.

## Acceptance criteria

- [x] `pnpm dev` runs locally with health page at `/`
- [x] `pnpm db:push` creates SQLite at `data/app.db`
- [x] `/api/health` returns OK
- [x] Socket.io attaches and clients can connect
- [x] `docker compose up --build` runs on Windows
- [x] README documents stack and LAN access basics

## Dependencies

None (first ticket).

## Key decisions

- Target domain: `eurovision.grymare.com` on Cloudflare (public in Phase 3).
- Design for **5–15 guests** typical (~30 headroom); WAL mode enabled for concurrent reads/writes.
