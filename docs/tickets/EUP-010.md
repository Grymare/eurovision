# EUP-010 — Host voting controls

| Field | Value |
|-------|-------|
| **Status** | Done |
| **Phase** | MVP (Phase 1) |
| **Labels** | `mvp`, `feature` |

## Summary

Host opens and closes voting. When closed, ballots lock — no further edits (including **Edit my vote**).

## Acceptance criteria

- [x] Host can transition party to `voting_open` and `voting_closed`
- [x] API rejects vote writes when not `voting_open`
- [x] Guests see state change in real time
- [x] Minimum 10 entries enforced before open (full ballot size; see `MIN_BALLOT_ENTRIES`)

## Implementation

- Host controls: **Start voting**, **Close voting**, **Reopen voting**
- `VoteBallot` accepts `votingLocked` — hides edit UI and shows read-only summary when closed
- State changes broadcast via existing `voting_status` socket events

## Dependencies

- EUP-009

## Key decisions

- Manual host control for MVP (no auto timers).
- Host may reopen voting from `voting_closed` before presentation.
