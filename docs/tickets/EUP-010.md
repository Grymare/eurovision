# EUP-010 — Host voting controls

| Field | Value |
|-------|-------|
| **Status** | Backlog |
| **Phase** | MVP (Phase 1) |
| **Labels** | `mvp`, `feature` |

## Summary

Host opens and closes voting. When closed, ballots lock — no further edits (including **Edit my vote**).

## Acceptance criteria

- [ ] Host can transition party to `voting_open` and `voting_closed`
- [ ] API rejects vote writes when not `voting_open`
- [ ] Guests see state change in real time
- [ ] Minimum 5 entries enforced before open

## Dependencies

- EUP-009

## Key decisions

- Manual host control for MVP (no auto timers).
