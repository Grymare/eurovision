## Summary

Optional prep modes on the ballot page to help jurors decide favorites before assigning Eurovision points — especially useful while watching performances.

## Acceptance criteria

- [x] Drag-and-drop reorderable list of all party entries
- [x] “Use as my ballot” maps rank to classic 1–8, 10, 12 spread and pre-fills ballot slots
- [x] Prefill never auto-submits; juror can edit before submit

## Brainstorm (deferred ideas)

| Idea | Flow |
|------|------|
| Tier buckets | Sort into S / A / B / C / “out” while watching → assign points within tiers |
| Elimination rounds | Repeatedly drop least favorite until top 10 remain |
| Top 5 lock-in | Pick 5 favorites early, only score those + fill rest quickly |
| Mood tags | Tag banger / meh / skip → filter for scoring |
| Regional clusters | Compare within region first, then cluster winners |
| Watch-along checklist | Mark seen + heart; unhearted get 0 in quick-fill |
