# EUP-007 — Classic 12-point vote UI

| Field | Value |
|-------|-------|
| **Status** | Backlog |
| **Phase** | MVP (Phase 1) |
| **Labels** | `mvp`, `feature` |

## Summary

Ballot UI: assign points 1, 2, 3, 4, 5, 6, 7, 8, 10, 12 to **10 distinct countries**. Submit once; while voting is open, **"Edit my vote"** reopens the ballot intentionally (not accidental taps).

## Acceptance criteria

- [ ] Client validation for 10 unique countries and exact point set
- [ ] Submit persists vote; success state shows waiting UI
- [ ] **Edit my vote** flow with explicit confirm before editing
- [ ] Mobile-friendly touch targets; desktop keyboard usable
- [ ] Meets **WCAG 2.2 AA** (labels, errors, focus order)

## Dependencies

- EUP-006
- EUP-006D (design tokens), EUP-007A, EUP-007B recommended before polish

## Key decisions

- **Edit vote with confirm** while `voting_open` only.
