# EUP-008 — Vote storage & secrecy

| Field | Value |
|-------|-------|
| **Status** | Done |
| **Phase** | MVP (Phase 1) |
| **Labels** | `mvp`, `feature` |

## Summary

Persist votes in SQLite with atomic transactions. Allow updates while voting open. Enforce **score secrecy** — no aggregate or per-voter points via API before presentation.

## Acceptance criteria

- [x] Vote submit/update in transaction with party state check
- [x] Idempotent submit for same participant
- [x] Vote detail and score endpoints return 403 until `presenting` or `finished`
- [x] One vote row per participant per party

## Dependencies

- EUP-007

## Key decisions

- Secrecy enforced server-side and in Socket.io payloads (names only pre-reveal).
