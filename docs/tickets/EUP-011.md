# EUP-011 — Score aggregation service

| Field | Value |
|-------|-------|

| **Phase** | MVP (Phase 1) |
| **Labels** | `mvp`, `feature` |

## Summary

Server-side computation of country totals from all votes (including **host vote**). Used only after voting closed / during presentation.

## Acceptance criteria

- [ ] Aggregation function sums points per country across all participants
- [ ] Not exposed to clients until presentation phase
- [ ] Snapshot written to `party_results` when presentation completes
- [ ] Eurovision tie-break rules documented for EUP-013

## Dependencies

- EUP-010

## Key decisions

- **Host votes** included in totals like any guest.
