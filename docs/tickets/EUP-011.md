# EUP-011 — Score aggregation service

| Field | Value |
|-------|-------|
| **Status** | Done |
| **Phase** | MVP (Phase 1) |
| **Labels** | `mvp`, `feature` |

## Summary

Server-side computation of country totals from all votes (including **host vote**). Used only after voting closed / during presentation.

## Acceptance criteria

- [x] Aggregation function sums points per country across all participants
- [x] Not exposed to clients until presentation phase
- [x] Snapshot written to `party_results` when presentation completes
- [x] Eurovision tie-break rules documented for EUP-013

## Implementation

- `src/lib/party/score-aggregation.ts` — totals, per-country point receipts, snapshot builder
- `snapshotPartyResults()` runs when party transitions to `finished`
- `GET /api/parties/[partyId]/scores` — live totals during `presenting`, frozen snapshot during `finished`
- Tie-break order documented in `EUROVISION_TIEBREAK_POINT_ORDER` (applied in EUP-013 UI)

## Dependencies

- EUP-010

## Key decisions

- **Host votes** included in totals like any guest.
- Snapshot is immutable once written at end of presentation (`finished` state).
