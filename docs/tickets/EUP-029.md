# EUP-029 — Admin-only party creation

| Field | Value |
|-------|-------|
| **Status** | Backlog |
| **Phase** | Phase 2 |
| **Labels** | `phase-2`, `feature` |

## Summary

When account login exists (EUP-005), **only the site admin** may create and host parties. All other users — logged in or guest — can **join** existing parties only.

## Acceptance criteria

- [ ] Admin identified via **`ADMIN_EMAILS` env allowlist** (single admin — you only)
- [ ] Home page: **Create party** hidden until admin is logged in
- [ ] Non-admin logged-in users see **Join** only (no host/create UI; hide site header “Host” link)
- [ ] `POST /api/parties` returns **403** for non-admin callers (including anonymous)
- [ ] Dev quick-start / mock create endpoints remain localhost-only
- [ ] Admin who creates a party is still a **voter** in that party (same as MVP host flow)

## Out of scope

- Multiple admins or public party discovery
- Letting any registered user create parties

## Dependencies

- [EUP-005](EUP-005.md) — ship in same PR or immediately after

## Key decisions (locked)

- **Admin model:** `ADMIN_EMAILS` env allowlist, only you
- **Logged-out home:** no create-party UI at all (admin must log in first)
- **Build order:** first Phase 2 item (with EUP-005)
