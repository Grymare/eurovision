# EUP-004 — Party create & join

| Field | Value |
|-------|-------|
| **Status** | Backlog |
| **Phase** | MVP (Phase 1) |
| **Labels** | `mvp`, `feature` |

## Summary

Host creates a party (6-character code + shareable LAN URL) and receives a host session token. Guests join with **nickname only**. **Host is also a voter** with the same ballot flow as guests.

## Acceptance criteria

- [ ] Create party generates unique code and host session token
- [ ] Host participant record created so host can vote
- [ ] Join flow: code + nickname; reject duplicate nicknames in same party
- [ ] Shareable join URL works on LAN (`http://<ip>:3000/join/...`)
- [ ] Private access only — no public party listing

## Dependencies

- EUP-003

## Key decisions

- **Nickname-only MVP** — no login/register.
- **Host votes** — same rules as guests.
- Typical party size **5–15 guests** (architecture supports ~30).
