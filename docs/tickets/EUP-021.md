# EUP-021 — Import party from year

| Field | Value |
|-------|-------|
| **Status** | Backlog |
| **Phase** | Phase 2 |
| **Labels** | `phase-2`, `feature` |

## Summary

Host (admin) picks a Eurovision year when setting up a party → countries pre-filled from [EUP-020](EUP-020.md) dataset. Entries remain editable after import.

## Acceptance criteria

- [ ] Admin can select available year(s) and import entries into party
- [ ] Imported entries use catalog flags/names from year JSON
- [ ] Host can add, remove, or edit entries after import (same as MVP entry picker)
- [ ] Works with current-year dataset from EUP-020 v1

## Dependencies

- [EUP-020](EUP-020.md)

## Key decisions (locked)
