# EUP-034 — Rate limiting & basic security

| Field | Value |
|-------|-------|
| **Status** | Backlog |
| **Phase** | Phase 3 |
| **Labels** | `phase-3`, `feature` |

## Summary

Protect public endpoints from bots and strangers **without IP-based limits** (friends often share the same Wi‑Fi during parties).

## Acceptance criteria

- [ ] **Defer until after EUP-005** (auth + admin model in place)
- [ ] App-level limits keyed by **party code / session**, not client IP
- [ ] Cloudflare bot fight / WAF in front of tunnel (document setup)
- [ ] Party code entropy and brute-force considerations documented
- [ ] Join and vote endpoints protected; legitimate same-network guests not blocked

## Dependencies

- [EUP-005](EUP-005.md) + [EUP-029](EUP-029.md)
- [EUP-016](EUP-016.md) Cloudflare Tunnel

## Key decisions (locked)

- **Not IP-based** rate limiting for join/vote
- **Both:** app session limits + Cloudflare bot protection
