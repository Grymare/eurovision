# EUP-045 — Presentation fits viewport

| Field | Value |
|-------|-------|
| **Status** | Won't do (reverted — compact layout too small) |
| **Phase** | Phase 3 |
| **Labels** | `phase-3`, `feature` |

## Summary

On standard 1080p screens, the presentation scoreboard pushes host controls (“Give points 1–10”, etc.) below the fold. Fit toolbar + scoreboard + primary action within the viewport height.

## Acceptance criteria

- [ ] “Give points 1–10” / “Give 12 points” / “Next jury” visible without scrolling on 1920×1080
- [ ] Fullscreen mode uses full height; scoreboard scales (compact rows if needed)
- [ ] No clipping of flags or totals; reorder animation still works

Reverted May 2026 — forced viewport fit made rows too small; original scrollable presentation kept.

## Dependencies

- [EUP-018](EUP-018.md), [EUP-019](EUP-019.md) — presentation scoreboard

## Key decisions (locked)

- Flex column: toolbar (fixed) + scoreboard (flex-1) + controls (fixed bottom)
- Presentation-only density tweaks, not global scoreboard changes
