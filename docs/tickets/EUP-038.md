## Summary

Admin tooling to populate entry lists quickly when a new ESC year starts. Aligns with [EUP-020](EUP-020.md) data pipeline.

## Acceptance criteria

- [x] Research/use public ESC API for current-year entries where available
- [x] Manual list builder in admin UI when API unavailable
- [x] Export curated list as JSON (`data/eurovision/{year}.json`)
- [x] Import JSON into year catalog (feeds EUP-021 party import)
