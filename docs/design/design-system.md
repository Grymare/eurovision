# Grymare Eurovision — Design System (EUP-006D)

**Chosen direction: Variant D · Open Lines**

## Creative direction

| Decision | Choice |
|----------|--------|
| Mood | Luxury minimal — black stage, sharp geometry, restrained gold |
| Background | Subtle repeating circle pattern |
| Layout | Open sections separated by gold gradient lines — no boxed panels |
| Typography | Geist Sans only, uppercase headings |
| Nav | Muted links with gold underline on hover |
| Buttons | Gold gradient **border** (not loud fill); primary has faint gold tint |
| Party code | Gold gradient mono |

## Buttons

- **Primary (Create):** transparent + metallic gradient border ring + gold label  
- **Secondary (Join):** bottom bar — muted gradient accent on bottom edge; brighter line on hover  

## Navigation

Small muted uppercase links. Gold gradient line scales in on hover/focus — no bordered menu boxes.

## Section layout

`.section-stack` children get `.section-block` padding and a top gold gradient rule between siblings.

## Brand notes

Fan project for `eurovision.grymare.com` — avoid official Eurovision logo assets.
